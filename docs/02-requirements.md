# 02 需求规格（PRD）

> 需求编号用于工单与测试用例追溯：`F-*` 功能、`NFR-*` 非功能、`S-*` 页面。优先级：**P0** 必须（v1.0 阻塞）、**P1** 应该（v1.x）、**P2** 可选（backlog）。

## 1. 信息架构

```
底部导航（4 Tab）
├── 书架 Shelf            ← 收藏、更新提示、分组/标签
├── 历史 History          ← 最近阅读，按时间倒序
├── 浏览 Browse           ← 聚合搜索入口、源列表、分类（按源能力出现）
└── 我的 Me               ← 下载、本地漫画、规则管理、备份、设置、关于

二级页面
├── 搜索 S-Search            （全屏，输入 + 多源并发结果）
├── 源详情 S-Source          （单源搜索结果 / 分类浏览）
├── 漫画详情 S-Detail        （封面、简介、章节、收藏、下载、换源）
├── 阅读器 S-Reader          （全屏沉浸，无导航栏）
├── 下载管理 S-Downloads     （进行中 / 已完成 / 失败）
├── 本地库 S-Local           （目录扫描 / 手动导入）
├── 规则管理 S-Rules         （已安装规则、导入、校验、健康度）
├── 备份 S-Backup            （本地 / WebDAV）
└── 设置 S-Settings          （阅读、外观、网络、存储、隐私）
```

## 3. 页面规格

### 3.1 书架 S-Shelf

- **状态**：加载（骨架屏）、空（引导去搜索/导入规则）、正常、错误。
- **排序/筛选**：顶部下拉切换分组与排序；长按进入多选。
- **卡片信息**：封面 2:3、标题 2 行截断、角标（未读/更新/本地/下载）。
- **交互**：单击进详情；长按多选；下拉刷新触发检查更新（仅对启用源）。

### 3.2 搜索 S-Search

```
┌──────────────────────────────┐
│ ← [ 输入漫画名…        ] 搜索 │
├──────────────────────────────┤
│ 历史：xxx  xxx  xxx           │
├──────────────────────────────┤
│ ▸ 源A（12）            失败↻  │
│   [封面][标题 / 最新章]  …    │
│ ▸ 源B（8）                    │
│   …                          │
└──────────────────────────────┘
```
- 输入 300ms 防抖；回车立即搜索。
- 结果流式追加：某源先返回先展示，不等待全部完成。
- 单源失败折叠为一行状态；点开展开错误详情（错误码 + 原始消息 + 复制）。

### 3.3 漫画详情 S-Detail

- 头部：封面（可点击看大图）、标题、作者、状态（连载/完结）、源名、收藏按钮、下载按钮、换源。
- 简介：默认 4 行，展开全文。
- 章节：网格/列表切换、排序、已读/下载图标；「继续阅读」浮动按钮固定右下。
- 空章节：提示「源可能已变更」，提供刷新与打开源页面。

### 3.4 阅读器 S-Reader

见 [06-reader-kernel.md](06-reader-kernel.md)，页面级要求：
- 全屏沉浸（隐藏状态栏/导航栏），防误触边缘。
- 单击中区显示/隐藏菜单；返回键行为可配置（退出 / 显示菜单）。
- 底部进度条 + 章节名 + 页码；顶部返回、切换模式、更多。
- 音量键可选翻页；亮度手势在左边缘竖直滑动（可关）。

### 3.5 规则管理 S-Rules

- 列表项：名称、id、版本、语言、健康度（成功率/最近错误）、开关、更多（删除/查看 JSON/复制错误）。
- 导入：选择文件、粘贴 JSON、输入 URL；导入前执行 **Schema 校验 → 引用校验 → 试运行（可选）**。
- 失败提示必须包含 `JSON Pointer`（如 `/search/fields/cover/from`）与人类可读原因。
- 危险能力声明（脚本、非白名单域名、加密）以图标 + 导入确认弹窗呈现。

### 3.6 设置 S-Settings

| 分组 | 条目 |
| --- | --- |
| 阅读 | 默认模式、翻页方向、预取页数、音量键翻页、自动裁剪白边、双击缩放、长图切片 |
| 外观 | 主题、动态取色、纯黑、封面圆角、网格列数 |
| 网络 | 超时、重试次数、图片并发、限速、代理（P2）、自定义 UA |
| 存储 | 下载目录、图片缓存上限、清除缓存 |
| 隐私 | 崩溃日志开关、清除全部数据、免责声明 |
| 关于 | 版本、开源许可、致谢、检查更新 |

## 4. 非功能需求

| ID | 类别 | 要求 | 验证方式 |
| --- | --- | --- | --- |
| NFR-01 | 性能 | 冷启动 → 书架可交互 ≤ 1.5s（Pixel 4a 级） | Macrobenchmark |
| NFR-02 | 性能 | 翻页（已解码）首帧 ≤ 100ms；条漫滚动掉帧 < 5% | JankStats |
| NFR-03 | 内存 | 条漫连续阅读峰值 < 300MB；无 OOM | Profiler + 30 分钟浸泡 |
| NFR-04 | 包体 | 通用 APK ≤ 15MB（不含规则） | CI 产物检查 |
| NFR-05 | 兼容 | Android 8.0–16；主流国产 ROM 无致命崩溃 | 真机矩阵（至少 4 台） |
| NFR-06 | 离线 | 无网络时书架/历史/本地/已下载可用；在线入口明确置灰 | 飞行模式手测 |
| NFR-07 | 稳定 | 崩溃率 < 0.5%；ANR < 0.1% | 本地日志统计 + 用户上报 |
| NFR-08 | 安全 | 规则沙箱无文件/设备/任意网络能力；明文 HTTP 仅对用户显式允许的源 | 代码审计 + 单测 |
| NFR-09 | 隐私 | 无第三方分析 SDK；无后台自动上报；网络请求仅至用户配置源 | 网络抓包 + 依赖清单 |
| NFR-10 | 可访问性 | 支持字体缩放 200%、TalkBack 可操作菜单；对比度 ≥ 4.5:1 | Accessibility Scanner |
| NFR-11 | 可维护 | 单文件 ≤ 500 行；核心逻辑单测覆盖 ≥ 60% | CI 报告 |
| NFR-12 | 数据 | 数据库迁移不丢数据；降级安装不崩溃 | 迁移测试矩阵 |

## 5. 关键交互与边界用例

| 场景 | 期望行为 |
| --- | --- |
| 阅读中网络断开 | 已缓冲页可继续；失败页显示重试；提示不打断阅读 |
| 阅读中切后台再回来 | 保持当前页与缩放；不重新请求已解码图片 |
| 阅读中旋转屏幕 | 保持页码；双页模式按需切换 |
| 章节被源删除 | 进度回退到最近可用章节并提示 |
| 规则被禁用后打开其收藏 | 详情页可展示缓存元数据，但章节需重新启用源 |
| 下载中删除漫画 | 先取消任务再删记录；文件按选择删除 |
| SD 卡移除 | 下载任务暂停并标红；恢复后手动/自动续传 |
| 时区/语言切换 | 时间格式化即时更新；不影响数据 |
| 恶意规则（超大响应/死循环脚本） | 响应体截断、脚本超时中断、源进入 degraded |

## 6. 验收口径（Release Gate）

v1.0 发布必须同时满足：

1. P0 需求全部实现，并有对应自动化或手工测试记录。
2. NFR-01/02/04/07 达标（CI 与手测数据附在 release note）。
3. 至少 3 个社区规则包通过 golden fixture 测试（CI 中脱敏、离线 HTML）。
4. 全新安装 → 导入规则 → 搜索 → 阅读 → 下载 → 离线重读，全链路手工通过。
5. 备份在另一台设备（不同 Android 版本）恢复成功。
6. 安全审查清单（见 09）零高优问题。
