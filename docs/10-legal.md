# 10 法律合规

> 本文不是法律意见。项目面向个人学习与技术研究，**使用者需自行承担合规责任**。
> 本节结论用一句话概括：**我们只做工具，不做内容，也不提供能定位到具体内容的内置配置。**

## 1. 项目定位（合规的基础）

| 做 | 不做 |
| --- | --- |
| 提供通用阅读器与文件解析能力 | 内置、推荐、托管任何漫画资源 |
| 提供规则引擎与规范 | 内置指向具体站点的规则/域名/接口 |
| 让用户导入自己编写的规则 | 代用户批量获取、缓存、分发内容 |
| 支持用户下载自己有权访问的内容 | 破解付费墙、绕过登录、去除 DRM |
| 本地数据、无账号、无服务端 | 上传用户数据、做内容聚合服务 |

应用安装包内**不含**：漫画图片、章节文本、具体站点规则、站点域名白名单预设。仓库的示例规则只使用 `example.com` 占位。

## 2. 主要法律风险与中国法语境

| 风险 | 依据（参考） | 与本项目的关系 | 缓解 |
| --- | --- | --- | --- |
| 著作权直接侵权 | 《著作权法》复制权、信息网络传播权 | 应用本身不复制、不传播作品 | 零内置内容；不缓存他人页面到自有服务器 |
| 帮助/教唆侵权 | 《民法典》侵权责任编；司法解释中的帮助侵权 | 若应用明示引导用户访问盗版站，可能被认定帮助 | 不提供站点推荐；规则由用户导入；文档明确用途与边界 |
| 规避技术措施 | 《著作权法》第 49 条；《信息网络传播权保护条例》 | 若实现去 DRM/破解，风险极高 | 明确禁止；脚本能力禁止 DRM 解密；PR 拒绝此类功能 |
| 避风港不适用 | 避风港针对「网络服务提供者」 | 单机应用不是 ISP，不能主张通知删除免责 | 不假设免责；靠「不接触内容」降低风险 |
| 个人信息 | 《个人信息保护法》 | 无账号、无遥测、数据本地 | 隐私设计见 §5；不收集可识别信息 |
| 内容合规（成人内容） | 平台规则与属地法规 | 规则可能指向成人站点 | `adult` 标记默认隐藏；年龄确认；不提供推荐 |
| 分发渠道风险 | 应用商店审核政策 | 商店通常将「可访问盗版」判为违规 | 不上架商店，仅 GitHub Releases 分发 |
| 商标/冒充 | — | 规则 id 可能冒充官方 | 保留 `official.*` 前缀；投诉即下线 |

### 2.1 「规避」的边界（要说清楚）

本项目的设计目标是**降低风险**，不是「合法化」：

- 风险降低来自：不存储、不分发、不内置、不引导、不破解、不商用。
- 风险**仍然存在**：权利人可能主张「提供工具 + 用户群交流规则 = 帮助侵权」；不同司法辖区结论不同。
- 因此：**不承诺零风险**；不提供法律意见；不接受商业化定制（如「帮我做成能看 XX 站的 App」）。
- 若收到权利人通知，按 §6 流程处理，优先下架相关规则或功能，不争论。

## 3. 与 Cimoc 的关系与 GPL-3.0 合规

### 3.1 参考范围

- 参考其**产品形态**（双阅读模式、源管理、下载队列、备份）与 `Parser` 接口的**能力集合**（搜索/详情/章节/图片/检查更新/分类）。
- 参考其**架构思路**（源与 UI 解耦、图片 Header 注入、惰性章节），但抽象为数据驱动的规则引擎。
- **不复制**：源实现（`source/*.java`）、资源文件、站点域名与接口细节、签名密钥、图标与截图。

### 3.2 许可证选择

本项目选择 **GPL-3.0-only**（与 Cimoc 一致）。理由：

1. 若未来确需移植 Cimoc 的个别通用代码（如 SAF 封装），GPL 兼容，无需额外授权。
2. 防止有人将本项目闭源打包成「内置盗版源的商店应用」，保护社区生态。
3. 与常见依赖（Apache-2.0/MIT/BSD/MPL-2.0）兼容（MPL-2.0 与 GPL-3.0 兼容；引入前逐项核对）。

### 3.3 义务

- 分发二进制（APK）时**必须**附带完整源码或提供获取方式（Release 页面指向本仓库同一 tag 即可）。
- 保留版权声明与许可证全文（`LICENSE`）；新增源文件建议加 SPDX 头：
  ```kotlin
  // SPDX-License-Identifier: GPL-3.0-only
  ```
- 修改他人 GPL 代码需保留原作者版权与变更说明。
- 不得附加额外限制（如「禁止商用」与 GPL 冲突，不能写入许可证；如需表达意愿只能写在 README 的请求中，不具法律约束）。

### 3.4 贡献者

- 采用 **DCO**（`Signed-off-by`），不要求 CLA；贡献即同意以 GPL-3.0 授权。
- PR 模板要求勾选：「未包含版权内容/未包含真实站点规则/未引入不兼容许可证依赖」。

## 5. 隐私与权限

### 5.1 权限清单（目标）

| 权限 | 用途 | 说明 |
| --- | --- | --- |
| `INTERNET` | 访问用户配置的源 | 必需 |
| `ACCESS_NETWORK_STATE` | 判断网络类型、预取降级 | 可选 |
| `POST_NOTIFICATIONS` | 下载进度通知（Android 13+ 运行时申请） | 可拒 |
| `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_DATA_SYNC` | 长下载前台服务 | Android 14+ |
| `WAKE_LOCK`（可选） | 长时间下载/备份 | 尽量不用 |

**不申请**：`READ_EXTERNAL_STORAGE`/`MANAGE_EXTERNAL_STORAGE`（用 SAF）、`REQUEST_INSTALL_PACKAGES`、位置、通讯录、电话状态。

### 5.2 数据处理

- 无账号、无登录、无云端；书架/历史/进度/规则/下载均在设备本地。
- 无第三方统计/广告/崩溃上报 SDK；崩溃日志默认仅本地，用户可主动导出。
- 网络请求只发往用户启用规则所声明的域名；不经过项目自有服务器。
- WebDAV 凭据用 Android Keystore 加密；备份默认不含凭据。
- 卸载即删除私有数据；SAF 目录中的用户文件不主动删除。

### 5.3 隐私政策要点（用于关于页/仓库）

1. 我们不收集个人信息，也不需要账号。
2. 应用仅在你主动操作时访问第三方站点；请求内容与凭据由你提供的规则决定。
3. 数据存储在本地，卸载即删除；备份文件由你自行保管。
4. 第三方站点有其自己的隐私政策，本项目不对其负责。
5. 联系渠道（issue/邮箱）用于合规与安全问题。

## 6. 投诉与下架机制

### 6.1 渠道

- GitHub Issue（私密安全报告）：`SECURITY.md` 中的流程；侵权投诉使用 `.github/ISSUE_TEMPLATE/takedown.yml`。
- 邮件：`<maintainer-email>`（占位，发布前填入）。
- 处理时限：**72 小时内首次响应**，核实后立即下架相关规则/索引条目或移除功能。

### 6.2 机制设计（技术侧配合）

1. **规则可撤销**：索引与 App 资产双通道 `revoked` 列表，命中即禁用。
2. **规则可下架**：索引删除条目；已安装用户下次刷新索引时收到「已撤销」提示。
3. **版本可回滚**：Release 保留历史版本，必要时发布「安全版本」。
4. **仓库可整改**：删除争议内容、发布说明、保留处理记录。
5. **不留后门**：不内置远程执行、不静默推送可执行内容（规则是数据，且需签名/确认）。

### 6.3 投诉模板要点

- 权利人身份与联系方式；
- 权利证明（作品登记/授权链）；
- 涉嫌侵权的具体位置（URL/规则 id/版本）；
- 真实性声明与法律后果承诺；
- 我们只处理「本项目仓库内容」，不处理第三方站点的侵权内容（请直接联系站点）。

## 7. 内容分级与年龄

- 规则可声明 `adult: true`；默认在源列表隐藏，需在设置中开启「显示成人源」并确认年龄。
- 不清洗、不推荐、不索引成人内容；不做内容审核（无内容）。
- 应用内不出现露骨预览图；封面来自用户所配置的源。

## 8. 分发与宣传红线

1. **不上架** Google Play、国内应用商店、F-Droid 官方仓库（规则生态与法律风险，F-Droid 通常也拒绝此类应用）。
2. **不宣传**「可看 XX 漫画」「免费看全网」等表述；README/Release 只描述工具能力。
3. **不提供**预配置规则包下载链接；社区规则仓库由第三方维护，本项目不背书。
4. **不接**商业推广、代搭建、定制「内置源」需求。
5. 发布页附免责声明与投诉入口。
