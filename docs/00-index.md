## 术语表

| 术语 | 含义 |
| --- | --- |
| **源 / Source** | 一个第三方站点的解析能力集合，由一条规则包定义；应用自身不含源。 |
| **规则包 / Rule Pack** | 描述某个源的 JSON 文件（可附带 JS 钩子），是 v1 的插件形态。 |
| **cid** | 漫画在某个源内的稳定标识（URL 中的数字/字符串），与本地自增 id 不同。 |
| **path** | 章节在源内的定位串（通常是 URL 或路径片段），对应用透明。 |
| **lazy 章节** | 章节图片列表需要二次请求才能得到，阅读时按页解析。 |
| **聚合搜索** | 多源并发搜索并按到达顺序交错展示结果。 |
| **健康度** | 源最近的请求成功率状态机：healthy / degraded / disabled。 |
| **SPI** | Source Provider Interface，源引擎扩展接口（Kotlin `SourceEngine`）。 |
| **ADR** | Architecture Decision Record，架构决策记录（见 03 附录）。 |
| **DoD** | Definition of Done，完成定义（见 08）。 |

## 文档维护规则

- 文档与代码同仓库、同 PR 变更；行为变更未更新文档视为未完成（见 09）。
- 决策变更必须新增或修订 ADR，不允许只改实现。
- 禁止在文档中写入真实盗版站点域名、可复制的侵权规则；示例统一使用 `example.com`。
