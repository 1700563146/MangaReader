# M5 验证记录（核心完成）

日期：2026-11-04 · 范围：规则生态（验签/撤销/CLI/健康度展示）

## 已完成

| 能力 | 实现 |
| --- | --- |
| 索引模型 | `RuleIndex`/`RuleIndexEntry`/`RuleIndexSignature`，严格反序列化 |
| JCS 规范化 | `JsonCanonicalizer`：键排序、无空白、字符串转义、布尔/整数最短形式 |
| Ed25519 验签 | `RuleIndexVerifier`：签名覆盖「除 signature 外整棵树」，支持 keyId 轮换与多公钥内置 |
| 哈希校验 | `RuleContentVerifier.sha256/verify`（规则文件内容校验） |
| 撤销列表 | `RevocationList`：`version = null` 撤销全部，否则撤销 ≤ 版本；资产 `revoked.json` 可下发 |
| 撤销执行 | `SourceManager` 安装拒绝、`ref()` 拒绝；规则页自动禁用并展示「已撤销」，开关锁定 |
| 健康度展示 | 规则页显示 health / failStreak / lastErrorCode（搜索引擎已按成功失败更新） |
| RuleLint CLI | `tools/rulelint`：多文件校验、JSON Pointer 输出、错误退出码；供规则仓库 CI 使用 |

## 使用 RuleLint

```bash
./gradlew :tools:rulelint:run --args="D:/path/to/rule.json"
```

输出示例：

```
OK   D:/Code/Manga/docs/examples/demo-source.json  (community.example v1.0.0)
检查完成：1 个文件，错误 0 个，警告 0 条
```
