# M8 验证记录：源库与 CJS 预留

日期：2026-11-05 · 范围：第三方源库浏览/安装、CJS 源格式预留

## 背景

用户提出接入现成源库（venera-configs）。实测后确认两条硬约束：

1. **合规**：项目零内置源，索引地址必须由用户自填（AGENTS.md、docs/10）。
2. **技术**：venera 源是 `class X extends ComicSource` + `async/await`，
   **Rhino 1.9.2（最新）不支持 `class` 与 `async/await`**，无法直接运行。
   详见 [ADR-007](../adr/ADR-007-cjs-source-engine.md)。

因此本轮做的是「**把格式抽象出来 + 让用户能浏览和登记源库**」，而不是硬跑 CJS。

## 已完成

| 能力 | 实现 |
| --- | --- |
| 源格式抽象 | `SourceKind`（RULE/CJS）+ `SourceRef` 密封接口（`RuleSourceRef` / `CjsSourceRef`） |
| 数据库 | `source.source_kind` 列，Room v2→v3 迁移 + 仪器化迁移测试 |
| 引擎分派 | `SourceRef.asRule()`：非规则源抛 `SourceFailure(RULE_INVALID)` 并给出可读原因 |
| 索引解析 | `SourceLibraryParser`：兼容 venera 数组格式与带签名的 JSON 规则索引 |
| 源库客户端 | `SourceLibraryClient`：仅 https（debug 放行本机 http）、2MB 上限、sha256 校验、按内容识别格式 |
| CJS 登记 | `SourceManager.installCjs()`：保存脚本与元数据，`enabled = false`，UI 明确提示 |
| 源库 UI | 设置 →「源库」：填索引 URL → 拉取列表 → 逐条安装 |

### 设备端到端（Android 16 模拟器）

2. 列表显示 33 条，每条带 `id · v版本 · CJS` 标记与「安装」按钮。
3. 点「安装」（本地提供假 CJS 文件）→ 提示：
   「已登记「测试CJS源」，但 CJS 源需要 ES2020 引擎，当前版本无法运行（已保存，未启用）」。
4. 无 FATAL。

### 错误处理

| 场景 | 结果 |
| --- | --- |
| 外网 CDN 不可达 | 提示「拉取索引失败：…timeout」，不崩溃 |
| 源文件 404 | 提示「安装失败：HTTP 404」 |
| http 地址（release 语义） | 拒绝并提示「索引地址必须为 https」 |
| 索引非法 JSON | 提示具体原因，列表为空 |

## 已知限制

| 项 | 说明 |
| --- | --- |
| CJS 不能运行 | 需 ES2020 引擎（QuickJS），见 ADR-007 的接入路径 |
| 索引地址不持久化 | 每次进入需重新填写；后续可加「收藏的索引」 |
| venera 无签名 | 该格式无 sha256/签名，安装时只能信任传输层（https） |
| 规则索引 UI | 带签名的 JSON 规则索引已能解析，但尚未接入公钥校验流程 |

## 下一步（若继续）
