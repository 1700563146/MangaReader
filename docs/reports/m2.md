# M2 验证记录

日期：2026-11-04 · 范围：Compose 阅读器内核

## 交付

| 能力 | 实现 |
| --- | --- |
| 翻页 | `HorizontalPager`（LTR/RTL）、`VerticalPager`（TTB），`beyondViewportPageCount=1` |
| 条漫 | `LazyColumn` + 高度回填 + 位置保持 |
| 双页 | 每屏两页、末页单占，`spreadCount` 计算；横图配对留待 M3 |
| 缩放 | 自定义 `ZoomState`（1–5x、边界 clamp、双击 2.2x） |
| 手势 | `zoomable` 修饰符：双指缩放、放大后单指平移；单指拖动**不消费**事件，交给 Pager/列表 |
| 点击区 | 左 30% / 中 40% / 右 30%，RTL 自动反向；长按切换模式 |
| 预取 | `ReaderPrefetcher` 窗口 `[page-1, page+4]`，窗口外取消，Coil `enqueue` 预热 |
| 图片 | Coil 3 + `httpHeaders` 注入 Referer/Cookie；单页失败可局部重试 |
| 进度 | `ProgressSink` 回调（demo 打印日志）；数据库接线在 M3 的 ReaderRoute |
| 沉浸 | 隐藏系统栏（手势上滑临时显示），退出恢复 |
| 演示入口 | Debug 设置页 →「阅读器演示」，本地生成 8 张占位图，不含任何漫画内容 |

## 设备验证（Android 16 模拟器 1080×2400）

- 翻页滑动：第 2 页进度日志 `page=2/8` ✅
- 菜单：页面/章节/模式/双页/退出/收起 ✅
- 条漫切换：滚动正常，切换时保留页码（修复 initial index）✅
- 双页：单屏两页渲染 ✅（截图见下）
- 沉浸模式：状态栏/导航栏隐藏 ✅
- 无 FATAL/ANR（6 次连续翻页）✅

## 帧率冒烟（**仅记录，不作门禁**）

| 指标 | 值 |
| --- | --- |
| 连续翻页 6 次渲染帧 | 175 |
| Janky frames | 39（22.29%） |
| p50 / p90 / p95 / p99 | 31 / 44 / 53 / 97 ms |

> 模拟器使用 SwiftShader 软件渲染 + Debug 构建，不能代表真机。**M2 性能决策门顺延到 M7**：真机 Macrobenchmark（Pixel 4a 级）测「翻页首帧 ≤100ms、条漫掉帧 <5%、内存 <300MB」；不达标时按 ADR-006 回退自定义 View 画布（`ReaderController` 契约不变）。
