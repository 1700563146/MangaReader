## 说明

- 冷启动 8.2s 为模拟器 + 软件渲染 + debug + 首次启动，**不作为性能基线**；M7 用真机 Macrobenchmark 统计。
- Debug 包 applicationId 带 `.debug` 后缀，便于与 release 共存。
- Release 当前使用 debug 签名（仅本地验证）；正式签名在 M7 接入 CI Secrets。
